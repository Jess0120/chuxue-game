# 初雪 — 夢落下的原點（網頁小遊戲）

改編自原創故事〈初雪〉的 2D 劇情冒險小遊戲。
玩家扮演 **李雨真**，在午夜港口的夢境裡逃亡、聆聽、看準時機逃脫，最後回到 2009 年那個雨夜，拾回關於 **延東宇** 的記憶。

- 遊玩時間：約 4～8 分鐘（含劇情）
- 純 HTML / CSS / JavaScript（Canvas 2D），**不需要安裝、不需要網路**
- 電腦（鍵盤）與手機／平板（觸控）都能玩

## 怎麼開始

直接用瀏覽器（Chrome、Edge、Firefox、Safari）**雙擊 `index.html`** 即可。
手機建議橫向遊玩；也可以把整個資料夾放上 GitHub Pages 等靜態網站空間。

## 章節與玩法

| 章節 | 玩法 | 劇情 |
|---|---|---|
| 序章 | 劇情 | 在午夜港口醒來，斗篷男現身：「李雨真，同學。」 |
| 第一章　午夜港口 | 橫向平台跳躍＋追逐 | 甩開他的手，往貨櫃最上層奔跑，身後的黑影步步逼近。 |
| 第二章　聆聽 | 節奏判定 | 閉上眼睛聆聽腳步聲，波紋與圓環重疊時按下；最後倒數「3、2、1——就是現在」。 |
| 過場 | 劇情 | 沉入海底、從夢中醒來；東宇現身擋在她面前。 |
| 第三章　看準時機 | 潛行＋逃脫 | 趁斗篷男盯著東宇時移動，紅光掃來時停下或躲進陰影；爆炸後逃離火海。 |
| 第四章　2009・雨夜 | 自動奔跑閃避 | 回到 2009 年，冒雨追著東宇跑向學校，跳過水窪與障礙物。 |
| 終章　初雪 | 劇情＋結算 | 想起第一次相遇的那天：「同學妳好，我叫延東宇。」 |

每章都有 **記憶碎片（雪花）** 可以收集，結局會顯示收集數、重來次數與遊玩時間。
失敗時可以立刻從該章重來，不會回到開頭。

## 操作方式

| 動作 | 鍵盤 | 觸控 |
|---|---|---|
| 左右移動 | ← → 或 A D | 左下 ◀ ▶ |
| 跳躍 | ↑、W 或 空白鍵（長按跳更高） | 右下「跳」（第四章點擊畫面也可） |
| 確認／翻頁／節奏判定 | Enter、空白鍵 或 點擊畫面 | 點擊畫面 |
| 跳過整段劇情 | Esc | — |
| 靜音／全螢幕 | M ／ F | 右上角按鈕 |

## 技術重點

- **Canvas 2D 繪圖**：固定 960×540 邏輯解析度，依螢幕像素密度自動提高解析度，CSS 等比縮放。
- **角色全部用程式繪製**（`sprites.js`），沒有用圖片，造型依照漫畫設定（長黑髮＋白高領、黑短髮＋黑大衣、黑斗篷）。
- **平台物理**：分軸 AABB 碰撞、重力、可變跳躍高度、土狼時間（coyote time）與跳躍預輸入，讓操作手感更寬容。
- **音效全部即時合成**（Web Audio API）：腳步、槍聲、爆炸、水花與鋼琴琶音背景音樂，不需要音檔。
- **天氣粒子系統**：初雪、2009 年的雨、火星。
- **資料與邏輯分離**：劇情台詞、章節說明與流程表都在 `story.js`，改劇情不用動遊戲邏輯。
- **自動化測試**：網址加上 `?auto=1` 會啟用自動遊玩機器人，從頭玩到結局（可用 Playwright 無頭瀏覽器跑）。
- 使用一般 `<script>` 而不是 ES Module，因為瀏覽器會擋 `file://` 載入模組，這樣雙擊就能玩。

### 除錯用網址參數

| 參數 | 作用 |
|---|---|
| `?stage=3` | 從標題直接進入第三章 |
| `?auto=1` | 自動遊玩（測試用） |
| `?fast=1` | 劇情文字顯示完自動翻頁 |

## 檔案結構

```
chuxue-game/
├── index.html          進入點：canvas、觸控按鈕、載入腳本
├── style.css           版面、16:9 縮放、觸控按鈕樣式
├── js/
│   ├── engine.js       底層：輸入、音效合成、天氣粒子、圖片載入、文字工具
│   ├── sprites.js      角色與收集物的向量繪製
│   ├── story.js        劇情台詞、角色資料、章節說明、遊戲流程表
│   ├── stages.js       四個關卡（共用基底類別 Stage + Stage1～4）
│   └── main.js         場景管理（載入／標題／過場／關卡／結局）與主迴圈
├── assets/
│   ├── panels/         過場插圖（取自〈初雪〉條漫分鏡）
│   └── portraits/      對話框頭像
└── screenshots/        遊戲截圖
```

## 內容說明

原著中較直接的暴力與血腥描寫，在遊戲中改為點到為止的旁白與淡出，不顯示受傷畫面。
