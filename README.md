# 初雪 — 夢落下的原點（網頁小遊戲）

改編自原創故事〈初雪〉的 2D 劇情冒險小遊戲。
玩家扮演 **李雨真**，在午夜港口的夢境裡逃亡、聆聽、看準時機逃脫，回到 2009 年那個雨夜；醒來之後，再一步一步查出那一夜頂樓真正發生了什麼。

> **第 1～4 章劇情為遊戲原創，非小說原作。**

- 遊玩時間：序章約 4～8 分鐘；完整版（第 1～4 章完成後）預估 30～40 分鐘
- 目前進度：序章完成、第一章〈碎片〉、第二章〈頂樓〉、第三章〈港口〉完成，第四章製作中
- 純 HTML / CSS / JavaScript（Canvas 2D），**不需要安裝、不需要網路**
- 電腦（鍵盤）與手機／平板（觸控）都能玩

## 怎麼開始

直接用瀏覽器（Chrome、Edge、Firefox、Safari）**雙擊 `index.html`** 即可。
手機建議橫向遊玩；也可以把整個資料夾放上 GitHub Pages 等靜態網站空間。

## 章節與玩法

| 章節 | 玩法 | 劇情 |
|---|---|---|
| 序章 | 劇情 | 在午夜港口醒來，斗篷男現身：「李雨真，同學。」 |
| 序章・一　午夜港口 | 橫向平台跳躍＋追逐 | 甩開他的手，往貨櫃最上層奔跑，身後的黑影步步逼近。 |
| 序章・二　聆聽 | 節奏判定 | 閉上眼睛聆聽腳步聲，波紋與圓環重疊時按下；最後倒數「3、2、1——就是現在」。 |
| 過場 | 劇情 | 沉入海底、從夢中醒來；東宇現身擋在她面前。 |
| 序章・三　看準時機 | 潛行＋逃脫 | 趁斗篷男盯著東宇時移動，紅光掃來時停下或躲進陰影；爆炸後逃離火海。 |
| 序章・四　2009・雨夜 | 自動奔跑閃避 | 回到 2009 年，冒雨追著東宇跑向學校，跳過水窪與障礙物。 |
| 序章・終　初雪 | 劇情 | 想起第一次相遇的那天：「同學妳好，我叫延東宇。」 |
| **第一章　碎片** | 房間點擊調查＋對話選擇 | 醒來後在房裡找到四人合照、四手聯彈節目單、舊剪報與胖達的手機；與母親、東宇的對話選擇會影響信任。 |
| **第二章　頂樓** | 劇情回放＋節奏關「門後」＋對話選擇 | 東宇說出他的版本（中間有一段刻意的空白）；貼在鐵門上重聽十年前的聲音——三十下，停兩下；在警局選擇自己站在哪一邊。 |
| **第三章　港口** | 對話選擇＋縮短版奔跑／聆聽／火海 | 夢在現實裡重演一次。這一次可以回頭、可以不跑、可以把刀丟進海裡。四個中間結局：①沉海（Game Over，回到 3-2 存檔點）、②火海、③門內（要在第二章聽出拍子）、④刀。劇本粗體句（與夢不同的地方）以暖色字顯示、多停一下。 |
| 第四章　初雪 | （製作中） | 依中間結局②③④與信任分成結局 A／B／C＋延伸結局〈原點〉。 |

每章都有 **記憶碎片（雪花）** 可以收集（序章 23 片＋第一章 7 片＋第二章 6 片＋第三章 5 片，目前共 41 片；全部完成後共 45 片），失敗時可以立刻從該章重來，不會回到開頭。

第一章起每章開頭會自動存檔（checkpoint），標題畫面出現「繼續」即可從最近的章節開頭接著玩。對話選擇不會顯示數字，信任變化時角落會短暫出現小圖示（東宇＝鈕扣、阿昊＝琴鍵）。

## 記憶碎片、回憶圖鑑與隱藏結局

- **拾回碎片**時，畫面會短暫出現那片碎片對應的回憶文字（取自原著〈初雪〉的句子）。
- 序章・一、三、四撿畫面上的雪花；序章・二（節奏關）沒有雪花，改成 **連續 3、6、10 拍不失誤** 各得一片。
- 第二章：回放中點擊畫面上的雪花（話筒、掛鎖）；節奏關「門後」**最高連續命中 ≥ 20 拍、且兩次休止都沒有按**，才算「聽出來」（`heardCount`），並得到碎片。沒聽出來可以當場「再聽一次」，或之後在圖鑑第二章分頁按「重聽門後」（R）——只在第三章開始前會改到存檔。
- 第三章：5 片碎片都在劇情裡——3-2「阿昊。」那一格必得，其餘四片各對應一個中間結局（①沉海也算），要全收需要重玩不同路線。進入第三章後，圖鑑「重聽門後」不再改動存檔裡的 `heardCount`。
- 第二章東宇回放裡有一格約 1.5 秒、只有雨聲的灰色空白畫面：**這是刻意的伏筆，不是錯誤**，第四章才會補上。
- **回憶圖鑑**：標題畫面選「回憶圖鑑」（或按 G、或點擊按鈕），結局畫面也能進入。依章節列出所有碎片，還沒拾回的顯示「？？？」。
- 圖鑑用瀏覽器的 `localStorage` 記住「曾經拾回過」的碎片，**跨多次遊玩累計**；死亡重來、重複撿同一片都不會重複計算。圖鑑裡已收錄的碎片，在關卡中會畫得比較淡。
- **延伸結局〈原點〉**（標示為「延伸結局・非原作」）：累計拾回全部碎片後，正常結局「同學妳好，我叫延東宇」之後會多播一段隱藏劇情；沒收齊時，結局畫面會提示「收集所有記憶碎片，或許能看見另一個結局」。解鎖後可在圖鑑按「重溫延伸結局」（H）再看一次。
- **改文字**：所有碎片文字與隱藏結局台詞都集中在 `js/story.js` 的「★ 記憶碎片與隱藏結局」區塊（`CX.MEMORIES`、`CX.CUTSCENES.hidden`、`CX.HIDDEN_TEXT`）。
- 想清除圖鑑紀錄：在瀏覽器主控台執行 `CX.memory.reset()`。

| 動作 | 鍵盤 | 觸控 |
|---|---|---|
| 左右移動 | ← → 或 A D | 左下 ◀ ▶ |

## 技術重點

- **Canvas 2D 繪圖**：固定 960×540 邏輯解析度，依螢幕像素密度自動提高解析度，CSS 等比縮放。
- **角色全部用程式繪製**（`sprites.js`），沒有用圖片，造型依照漫畫設定（長黑髮＋白高領、黑短髮＋黑大衣、黑斗篷）。
- **平台物理**：分軸 AABB 碰撞、重力、可變跳躍高度、土狼時間（coyote time）與跳躍預輸入，讓操作手感更寬容。
- **音效全部即時合成**（Web Audio API）：腳步、槍聲、爆炸、水花與鋼琴琶音背景音樂，不需要音檔。
- **天氣粒子系統**：初雪、2009 年的雨、火星。
- **資料與邏輯分離**：劇情台詞、章節說明與流程表都在 `story.js`，改劇情不用動遊戲邏輯。
- **自動化測試**：網址加上 `?auto=1` 會啟用自動遊玩機器人，從頭玩到結局（可用 Playwright 無頭瀏覽器跑）。
- 使用一般 `<script>` 而不是 ES Module，因為瀏覽器會擋 `file://` 載入模組，這樣雙擊就能玩。

### 除錯用網址參數

| 參數 | 作用 |
|---|---|
| `?stage=3` | 從標題直接進入第三章 |
| `?auto=1` | 自動遊玩（測試用，會順便拾回所有碎片） |
| `?fast=1` | 劇情文字顯示完自動翻頁 |
| `?ch=1`／`?ch=2`／`?ch=3` | 從第一章〈碎片〉／第二章〈頂樓〉／第三章〈港口〉開始 |
| `?pick=1` | 自動遊玩時，所有選擇都選第 2 個選項（預設第 1 個），用來測分支 |
| `?picks=1,0,2` | 自動遊玩時依序指定每一次選擇（0 起算，只算畫面上看得到的選項；用完後改用 `pick`） |
| `?vars=heardCount:true,trustDong:3` | 開場先設定變數（測第三章分支用） |
| `?fail=1` | 自動遊玩時，節奏關「門後」第一次故意在休止拍按下（測失敗與重聽） |

#### 第三章分支測試網址（皆從 `index.html?ch=3&auto=1` 開始）

| 加上的參數 | 路線 | 結果 |
|---|---|---|
| `&picks=1,0,0,1,0` | 一個人去 → 照夢跑 → 刺 → **①沉海** → 回 3-2 → 不跑 → 逃 | `dreamRetry=true`、`midEnd=2` |
| （不加） | 打給東宇 → 跑 → 刺（東宇趕到） → 逃 | `stabbed=true`、`midEnd=2` |
| `&picks=0,0,1,1` | 打給東宇 → 跑 → 刀丟進海 → 3-4 → 撿玻璃刺 | `threwKnife=true`、`midEnd=4`、`trustHao=0` |
| `&vars=heardCount:true&picks=0,1,1` | 不跑 → 3-4（聽出拍子） → 站到兩人中間 | `midEnd=3` |
| `&vars=heardCount:true,toldDream:true,askedMore:true&picks=1,1,2` | 一個人去 → 不跑 → 握刀刺 | `midEnd=4`、`trustHao=0` |
| `&vars=toldDream:true&picks=1,0,0` | 一個人去但說過夢 → 刺 → 不觸發① | `stabbed=true`、`midEnd=2` |

## 內容說明

**第 1～4 章劇情為遊戲原創，非小說原作。** 延伸結局〈原點〉亦為遊戲延伸，非原作情節。

原著中較直接的暴力與血腥描寫，在遊戲中改為點到為止的旁白與淡出，不顯示受傷畫面。
